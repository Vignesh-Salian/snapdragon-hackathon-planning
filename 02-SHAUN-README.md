# Work Assignment: Frontend Dashboard

*   **Module Owner:** Shaun
*   **Module Name:** React Monitoring Dashboard
*   **Objective:** Develop a responsive web interface to display live cold-box telemetry, trigger fraud warning alerts, display demand forecasts, and manage local inventory.

---

## 1. Why This Module Exists

The dashboard translates raw system data into visual indicators for hospital administrators. It enables users to monitor transport conditions, view prediction metrics, and take immediate action on alert flags.

---

## 2. Responsibilities & Folders Owned

*   **Repository Folder:** `/dashboard`
*   **Primary Tasks:**
    *   Implement blood stock inventory views.
    *   Build cold chain live monitoring interfaces.
    *   Expose real-time notification alerts (compromised blood, fraud warnings).
    *   Create simulation control widgets for demo presentations.

---

## 3. Features to Implement

1.  **Inventory Stock Panel:** Grid view of blood types showing active quantities and minimum required stock thresholds.
2.  **Live Telemetry Panel:** Line charts showing temperature logs, humidity, and peak shock values.
3.  **Active Alert Panel:** Pop-up warnings for temperature violations and shock spikes.
4.  **Prediction Viewer:** Display expected demand generated by the AI Engine.
5.  **Biometric Lockout Alert:** Real-time modal detailing donor fraud alerts with names and match confidence.
6.  **Simulation Controls:** Local mock buttons to trigger test telemetry packets for demonstration.

## 5. Interface Specifications

### APIs to Consume
*   `GET http://127.0.0.1:8002/api/v1/inventory/{hospital_id}` (Mithun's endpoint)
*   `POST http://127.0.0.1:8002/api/v1/inventory/update` (Mithun's endpoint)
*   `WebSocket ws://127.0.0.1:8002/ws/live` (Mithun's endpoint)

### Incoming Data Stream Contracts
*   **Event `TELEMETRY_UPDATE`:** Updates charts and cold-box card status.
*   **Event `FRAUD_ALERT`:** Displays a critical warning modal on screen.

## 6. Coding & Documentation Standards

*   **Language & Tech:** React, TypeScript, TailwindCSS, Chart.js.
*   **Coding Conventions:**
    *   Use functional components with explicit TypeScript interfaces for all component props.
    *   Isolate API requests inside `/dashboard/src/services/`.
    *   Implement clean component separation (pure display cards vs. state containers).
*   **Design System:** Modern dark mode layout. Use curated palettes (such as slate backgrounds, emerald/green for safe states, amber/yellow for warnings, rose/red for compromised states). Avoid raw primary colors.
